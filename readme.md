# 실시간 이모티콘 보내기

초보자 수업에서 학생들이 이모티콘으로 반응을 보내고, 강사와 학생이 실시간으로 함께 확인하는 웹앱입니다.

## 실행

인터넷에 연결한 뒤, 함께 제공된 `index.html`을 더블클릭하세요. 설치나 빌드는 필요하지 않습니다. HTML, CSS, JavaScript가 모두 이 파일에 들어 있습니다.

## 사용 방법

- **학생 모드:** 비밀번호 없이 들어갑니다. “👍 좋아요”, “❤️ 공감해요”, “👏 응원해요”를 눌러 반응을 보냅니다. 반복해서 보낼 수 있습니다.
- **강사 모드:** 비밀번호 `1004`를 입력합니다. 학생들의 반응과 종류별 누적 횟수, 전체 횟수를 확인합니다.
- **처음으로:** 역할 선택 화면으로 돌아갑니다. 강사 모드에 다시 들어갈 때는 비밀번호를 다시 입력해야 합니다.

여러 기기에서 같은 설정의 `index.html`을 열면 같은 반응을 공유합니다. 반별 구분이나 초기화 기능은 없으며, 기존 누적 횟수는 파일을 다시 열어도 유지됩니다.

## 연결과 전송 표시

- 상단에 실시간 연결 상태가 표시됩니다.
- 연결이 준비되지 않거나 데이터 읽기에 실패하면 전송 버튼을 사용할 수 없습니다.
- 전송 버튼을 누르면 서버 확인이 끝날 때까지 전송 확인 중으로 표시합니다.
- 서버가 저장을 확인한 경우에만 전송 성공 횟수에 포함합니다. 실패하면 전송 실패 안내가 표시됩니다.
- 전송 도중 연결이 끊기면 복구 후 전송을 계속할 수 있습니다. 확인 중인 반응이 있다면 창을 닫지 마세요. 창을 닫은 뒤의 미완료 전송 보존은 보장하지 않습니다.

## Firebase 설정

Firebase Realtime Database를 사용합니다. 별도의 로그인, 회원가입, Firebase Authentication, AI API 키 입력은 필요하지 않습니다.

- 프로젝트: `test-e1c46`
- 데이터 경로: `practice/reactions`
- 실제 데이터베이스 주소: `https://test-e1c46-default-rtdb.asia-southeast1.firebasedatabase.app`
- SDK: Firebase 10.12.5의 CDN compat 스크립트

제공된 `firebaseConfig`는 코드에 그대로 보관했습니다. 제공값의 `databaseURL`이 마크다운 링크 형식이므로, 실행 시 그 안의 실제 주소를 추출합니다. 임의의 데이터베이스 주소를 만들지 않습니다.

**추가 설정이 필요할 때의 첫 단계:** Firebase 콘솔에서 이 프로젝트의 Realtime Database 보안 규칙이 실습용 읽기·쓰기를 허용하는지 확인하세요.

## 제작 방식

반응 하나를 보낼 때 종류별 횟수를 서버에서 원자적으로 1 증가시키고, 고유 키를 가진 반응 기록을 함께 저장합니다. 두 변경은 한 번의 원자적 업데이트로 처리하여 동시 전송 시 단순 덮어쓰기로 횟수가 누락되는 것을 방지합니다.

데이터 구조는 다음과 같습니다.

```text
practice/reactions
├── counts
│   ├── like
│   ├── heart
│   └── cheer
└── events
    └── 고유 키
        ├── kind
        └── at
```

읽기 연결과 쓰기 연결을 분리하여, 전송 기기의 로컬 선반영을 저장 성공으로 표시하지 않도록 했습니다. 화면은 실시간 구독으로 갱신되며, 전체 횟수는 종류별 횟수의 합입니다.

최근 반응은 마지막 80개 기록을 구독하고, 최근 목록에는 최대 12개를 표시합니다. 누적 횟수는 이 표시 개수와 관계없이 유지됩니다. 반응 기록의 자동 삭제 기능은 없습니다.

Firebase 공식 설명: <https://firebase.google.com/docs/database/web/read-and-write>

## 보안에 관한 제작 설명

**비밀번호 `1004`는 실습용 화면 진입 제한이며 실제 데이터 보안을 보장하지 않습니다.** 비밀번호와 설정은 HTML 소스에서 볼 수 있습니다. 실제 데이터 접근 권한은 Firebase 보안 규칙으로 결정됩니다. 테스트 모드에서는 외부에서도 데이터를 읽거나 변경할 수 있으므로 개인정보나 민감한 정보를 저장하지 마세요.

## 확인 결과

### 확인 완료

- JavaScript 문법 검사 통과
- HTML 요소 식별자 중복 없음
- 코드가 참조하는 화면 요소 존재 확인
- `alert()`, `confirm()`, `prompt()` 미사용 확인
- 반응형 배치, 최소 16px 글자, 최소 44px 이상의 버튼을 코드에 적용

### 실제 실행 미확인

- Firebase 연결 및 실제 전송 성공·실패 동작
- 강사·학생 두 탭 사이의 실시간 반영
- 여러 학생의 동시 전송 시 실제 집계 결과
- 휴대폰·태블릿·노트북 화면 너비에서의 실제 배치 및 겹침 여부

제작 환경의 브라우저 URL 보안 정책이 로컬 파일 열기를 차단하여 브라우저 실행 검증은 완료하지 못했습니다. 코드 검사 결과가 실제 실행 검증을 대신하지는 않습니다.
